# grugbrain.dev fork
This is a contribution to the grugbrain.dev initiative by improving the site's readability, especially on mobile devices, making it responsive, and by adding dark mode support.

# Changelog
June 19 2026
- pushed the first version of the fork.

## Installing
Clone the repository
```sh
git clone git@github.com:ToniMaunde/grugbrain.dev.git
```

Then navigate to the directory
```sh
cd grugbrain.dev
```

Serve locally using
```sh
pnpm exec eleventy --serve
```

Build for production using by deploying the contents of the folder `_site` produced by the command below
```sh
pnpm exec eleventy
```

You can check [eleventy's website](https://www.11ty.dev/docs/) for more information.
